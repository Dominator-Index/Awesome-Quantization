# Cauchy-Schwarz Regularizers

**主分类：** 损失设计与优化景观。

**关联标签：** 目标函数、离散结构、通用正则化。

## 核心认知

可微正则项能够推动连续参数形成离散结构。

## 方法怎么做

用Cauchy–Schwarz不等式构造正则项；三值结构是其应用之一，也研究其他向量和矩阵结构。
