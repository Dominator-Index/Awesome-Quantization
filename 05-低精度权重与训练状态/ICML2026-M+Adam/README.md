# M+Adam: Low-Precision Training via Additive-Multiplicative Optimization

**主分类：** 低精度权重与训练状态。

**关联标签：** 加乘更新、有限精度、Adam与Madam。

## 核心认知

低精度下，加性与乘性更新会在不同权重尺度遇到停滞。

## 方法怎么做

结合Adam加性更新与Madam乘性更新，改善低精度权重优化。
