# ParetoQ: Improving Scaling Laws in Extremely Low-bit LLM Quantization

**主分类：** 量化表示、重建与位宽。

**关联标签：** 位宽缩放、训练配方、模型大小与精度。

## 核心认知

不同位宽对应不同表示变化和训练需求，需要统一条件下比较大小与精度。

## 方法怎么做

统一比较1、1.58、2、3、4 bit，并优化各位宽的量化函数与训练配方。
