# JacQuant: STE-Free Quantization-Aware Training via Learned Jacobian Surrogates

**主分类：** 梯度估计与可微量化。

**关联标签：** 学习型代理、Jacobian、STE-free。

## 核心认知

可学习的局部敏感性代理可用于改善低精度模型的更新。

## 方法怎么做

学习对角或分块Jacobian敏感性代理，结合方差缩减优化；不改变前向量化器。
