# StableQAT: Stable Quantization-Aware Training at Ultra-Low Bitwidths

**主分类：** 梯度估计与可微量化。

**关联标签：** 代理梯度、STE推广、Fourier分析。

## 核心认知

硬量化反向的代理梯度可以比恒等STE更平滑、稳定。

## 方法怎么做

从舍入算子的离散Fourier分析构造轻量代理梯度族，STE是其特例。
